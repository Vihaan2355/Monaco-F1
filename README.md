# Monaco-F1

A 3D CAD recreation of the iconic Formula 1 Monaco Grand Prix Winner's Trophy, featuring the Circuit de Monaco track layout, official ACM emblem, Monégasque flag accent, and a detailed display base.

- Accurate outline of the Monaco Track map integrated with the automobile club de monaco logo
